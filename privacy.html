Política de privacidad de Milo

Última actualización: 7 de octubre de 2026

Milo es una aplicación de uso personal y privado de Mauricio Muñoz (mmg.usb@gmail.com). No está disponible para el público.

Qué datos usa

  • Google Health: sueño, frecuencia cardiaca, HRV, SpO2, respiración, pasos, peso y registros de comida.
  • Google Calendar: eventos, para organizar la agenda y crear bloques de tiempo.
  • Google Drive: lectura de los archivos de una carpeta de exámenes médicos.

Para qué

Únicamente para generar recomendaciones, resúmenes y recordatorios para el propio titular de las cuentas.

Dónde se guardan

En las cuentas personales del titular (Google, Notion) y en su infraestructura privada (AWS). Los permisos de acceso se guardan cifrados.

Con quién se comparten

Con nadie. Los datos no se venden, no se usan para publicidad ni se transfieren a terceros. El uso de los datos obtenidos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

En cualquier momento, desde myaccount.google.com/permissions.
